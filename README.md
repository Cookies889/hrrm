# Hrrm

Zamienia nagranie głosu na głos villagera z Minecrafta.

## Instalacja (Windows 10 i 11)

1. Wejdź w [Releases](../../releases/latest) i pobierz `Hrrm-setup-…exe`.
2. Uruchom. Windows może pokazać niebieskie okno „System Windows ochronił ten komputer”,
   bo program nie ma płatnego certyfikatu. Kliknij **Więcej informacji**, potem **Uruchom mimo to**.
3. Instalacja nie pyta o hasło administratora. Skrót jest w menu Start.

## Jak używać

1. Przeciągnij nagranie na okno albo kliknij **Wybierz plik**. Działa WAV, MP3, OGG, OPUS (głosówki
   z Discorda i WhatsAppa), M4A, FLAC, a nawet film (MP4, MOV, MKV), z którego bierze dźwięk.
2. Wybierz tryb:
   - **Ze słowami**: słowa zostają, mówi villager,
   - **Samo hmm**: same „hmm” villagera w rytmie Twojego nagrania.
3. **Wysokość** i **Ile villagera** zmieniają brzmienie. Kliknij **Przerób na villagera**,
   posłuchaj i **Zapisz WAV**.

Nowe wersje program wykrywa sam i proponuje aktualizację. Instaluje tylko pliki podpisane przez autora.
